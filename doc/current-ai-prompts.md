# 当前 AI 提示词整理

本文档整理当前分支 `preview` 删除 V2 逻辑后的 AI 生成图提示词。当前只保留 Legacy 生成链路，并支持可选效果参考图与负面提示词。

## 1. 当前生成链路

```text
src/App.tsx
  generateWithAi()
    → buildAgnesPrompt(aiStyleId, aiPrompt, gridSize, maxColors, aiNegativePrompt, hasEffectReference)
    → generateAgnesImage({ prompt, file, effectFile, size, ... })
    → cropSubjectFromImage()
    → generatePattern()
```

后端只保留图片生成接口：

```text
POST /api/agnes/generate
```

## 2. 参考图输入

AI 生成现在支持：

- 主体参考图：必选，作为生成主体来源
- 效果参考图：选填，只参考风格、色块大小、轮廓处理、简化程度、构图密度和颜色控制方式

当用户上传效果参考图时，prompt 会追加说明：第一张图用于主体，第二张图只用于效果参考，不复制第二张图中的主体、文字、背景或具体内容。

## 3. 提示词来源

文件：`src/agnes/styles.ts`

核心导出：

- `AGNES_BASE_PROMPT`
- `AGNES_STYLE_PRESETS`
- `DEFAULT_NEGATIVE_PROMPT = '不要背景色'`
- `buildAgnesPrompt()`

最终 prompt 由以下部分拼接：

```text
基础拼豆像素画要求
+ 风格预设 promptSuffix
+ 网格 / 颜色约束
+ 效果参考图说明（如果有）
+ 用户补充描述
+ 最终输出约束
+ 负面提示词
```

## 4. 基础提示词目标

`AGNES_BASE_PROMPT` 的主要约束：

- 把参考图转换成适合拼豆量化的像素画，而不是普通插画或照片
- 主体占画面面积 75-90%
- 近景、紧凑裁切、主体居中
- 每个像素点对应最终图纸中的一格 / 一颗拼豆
- 清晰方形像素块、硬边缘、无抗锯齿
- 无渐变、无照片纹理、无柔光阴影
- 不生成真实拼豆、圆形豆子、底板、孔洞、网格线或纸张效果
- 背景使用纯色或极简背景
- 避免宽边距、小主体、大面积空白背景

## 5. 风格预设

| styleId | 中文名 | 主要目标 |
|---|---|---|
| `pixel-classic` | 经典像素 | 复古游戏精灵、大色块、清晰边缘 |
| `cute-chibi` | 可爱 Q 版 | 大头小身、圆润可爱、pastel 配色 |
| `flat-minimal` | 扁平简约 | 几何色块、少细节、主体大 |
| `retro-8bit` | 8-bit 复古 | NES 风格、粗颗粒、小色板 |
| `perler-craft` | 拼豆工艺感 | 扁平像素、适合量化、非真实豆子 |
| `simplified-real` | 写实简化 | 保留轮廓、减少阴影和细节 |

## 6. 网格与颜色约束

`buildPixelSpecPrompt(gridSize, maxColors)` 会根据用户配置追加约束。

当存在 `gridSize`：

- 指定横向像素数
- 每格对应一个独立像素点 / 一颗拼豆
- 输出可被放大显示，但必须保留低分辨率像素逻辑
- 按目标宽度规划细节密度
- 当 `gridSize <= 56` 时，要求进一步图标级简化

当存在 `maxColors`：

- 整张像素画最多使用指定数量的主要颜色
- UI 最大颜色数量上限为 50
- 使用有限调色板、大色块和高对比
- 不使用渐变、噪点或大量相近色模拟阴影

## 7. 用户补充描述

用户在「补充描述」输入框中填写的内容会直接追加到 prompt 中，适合表达：

- 要保留的主体或特征
- 要去掉的背景元素
- 构图要求，例如放大主体、减少留白
- 风格偏好，例如更可爱、更复古、更简约

## 8. 负面提示词

当前新增独立负面提示词输入框，默认值：

```text
不要背景色
```

构建 prompt 时会追加：

```text
负面提示词：不要背景色。
```

用户可以继续补充，例如：不要文字、不要水印、不要复杂背景。

## 9. 最终输出约束

`buildAgnesPrompt()` 末尾会追加最终约束：

- 输出用于后续量化的像素画源图
- 像素块边界清楚、色块连续、轮廓明确
- 不输出平滑插画、高清照片、复杂背景、文字、水印、边框或装饰网格
- 构图近景、紧凑裁切、主体居中
- 主体占画面 75-90%
- 背景纯色或极简
- 避免宽白边、过多留白、远景构图、小主体漂浮
